# 영어 한 걸음 (어머니용 캐나다 생활 영어 앱)

휴대폰·아이패드에서 열리는 웹앱이에요. 서버 없이 **GitHub Pages**로 올리고, 단어·문장은 **구글 시트**로 늘려 갈 수 있어요.

## 1주차에 들어 있는 것

- 👂 **소리 구분 게임**: f/p, v/b, l/r (기본) + i/ee, th/s, a/e (보너스). 두 단어 중 들려준 소리 고르기. 틀려도 감점 없이 마지막에 한 번 더 나와요.
- 🗣️ **이럴 때 쓰는 말** 5개: 듣기 → 따라 말하며 녹음 → 원어민과 이어서 비교 → 스스로 체크
- 🎮 **승부욕 장치**: 점수, 레벨(🐣→🚗→🦁→👑), 연속 학습일, 배지, 지난번·지난주와 비교, 실전 미션. (시간제한·가족 경쟁 없음)
- 글자 크기 3단계, 한글 발음 표기 켜기/끄기

### 1주차 이렇게 하세요 (하루 10분, 주 5일)

| 요일 | 할 일 |
|---|---|
| 월 | f/p: 소리 들어 보기 → 게임 1판 + 문장 2개 |
| 화 | v/b: 들어 보기 → 게임 1판 + 문장 2개 |
| 수 | l/r: 들어 보기 → 게임 1판 + 문장 2개 |
| 목 | 점수가 낮았던 세트 다시 + 아직 별이 없는 문장 |
| 금 | 세 세트 복습 + 이번 주 실전 미션 해 보기 |

주말은 쉬어도 돼요. 문장은 "잘 됐어요"를 3번 하면 마스터(⭐⭐⭐)예요.

---

## 1. GitHub에 올려서 열기

1. github.com 에서 **New repository** → 이름 `english-for-mom` → **Public** → Create.
   (무료 GitHub Pages는 Public 저장소만 돼요. 개인 정보는 들어 있지 않아요.)
2. 이 폴더 안의 파일 **전부**(index.html, app.js, style.css, data.js, config.js, manifest.json, sw.js, icons 폴더 등)를 저장소에 끌어다 놓기: **Add file → Upload files** → **Commit changes**.
3. 저장소 **Settings → Pages → Build and deployment**: Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save.
4. 1~2분 뒤 `https://내아이디.github.io/english-for-mom/` 로 열려요.

## 2. 어머니 아이폰·아이패드에 설치

1. **Safari**로 위 주소를 열어요. (크롬 말고 Safari)
2. 공유 버튼(네모에 화살표) → **홈 화면에 추가**.
3. 처음 녹음할 때 **마이크 허용**을 눌러야 해요.

## 3. 구글 시트로 단어·문장 늘리기 (선택)

1. 새 구글 시트를 만들고 탭 4개를 이름 그대로 만들어요: `groups`, `pairs`, `phrases`, `missions`
2. 각 탭에서 **파일 → 가져오기 → 업로드**로 `sheet-csv/` 폴더의 같은 이름 CSV를 넣어요 (현재 시트 바꾸기).
3. **공유 → 링크가 있는 모든 사용자 → 뷰어**.
4. 주소 `.../spreadsheets/d/`**`여기가 ID`**`/edit` 의 ID를 `config.js` 의 `SHEET_ID` 에 넣고 GitHub에서 저장.
5. 이제 시트에 줄을 추가하면 앱에 반영돼요. 앱을 **두 번 열어야** 새 내용이 보일 수 있어요. 시트가 안 열리면 내장 데이터로 동작해요.

시트 열 이름은 CSV 첫 줄 그대로 두세요. `pairs`의 `group`은 `groups`의 `id`와 같아야 하고, `core`가 TRUE인 그룹이 기본, FALSE면 보너스예요.

## 4. 진도를 시트에 남기기 (선택)

진도(점수, 연속일)는 기본으로 **그 기기에만** 저장돼요. 시트로도 보고 싶으면 `apps-script/Code.gs` 안의 설명대로 배포하고, 웹 앱 URL을 `config.js` 의 `APPS_SCRIPT_URL` 에 넣으세요. 시트에 `progress` 탭이 자동으로 생겨요. (기록만 남기고, 기기 간 진도 동기화는 아직 없어요.)

## 5. 고칠 때 알아둘 것

- 앱 파일이나 mp3를 고친 뒤에는 `sw.js` 맨 위 `eng-mom-v3` 숫자를 올려요 (v4, v5…). 안 올리면 기기에 예전 버전이 남을 수 있어요.
- 레벨 점수·오늘 목표 개수는 `app.js` 위쪽(`LEVELS`, `GOAL_QUIZ`, `GOAL_PHRASES`)에서 바꿔요.
- `data.js`는 내장 데이터예요. 시트를 쓰면 시트가 우선이에요.

## 영어 소리에 대해

- 단어와 문장은 **AI 음성(Kokoro, 미국 영어 여성)으로 미리 만든 mp3**예요 (`audio/` 폴더, 보통·천천히 2종류). 원어민 녹음은 아니에요.
- 아이폰·아이패드 기본 음성보다 자연스럽고, 기기나 설정과 상관없이 같은 소리가 나요. 한 번 열어 두면 인터넷이 끊겨도 들려요.
- mp3가 없는 문장(시트에서 새로 추가한 것 등)은 기기 내장 음성으로 대신 읽어요. 이때는 아이폰 옆 **무음 스위치**와 볼륨을 확인해 주세요.
- 원어민 녹음으로 바꾸고 싶으면 같은 이름의 mp3를 `audio/`에 덮어쓰면 돼요. 파일 이름은 영어 문장을 소문자로 하고 글자·숫자가 아닌 부분을 `-`로 바꾼 것이에요 (예: `could-i-get-a-fork-please.mp3`, 천천히 버전은 `...slow.mp3`).
- 새 문장의 mp3를 만드는 스크립트는 `tools/make_audio.py`예요. Kokoro 모델 파일이 필요해서 Claude에게 "새 문장 mp3 만들어 줘"라고 하시면 돼요.

## 알려진 한계 (솔직하게)

- **발음 자동 평가는 아직 없어요.** 지금은 "녹음해서 원어민과 이어 듣기 + 스스로 체크"예요. 자동 평가(Azure 등)는 다음 단계예요.
- AI 음성은 비슷한 소리(예: pine/fine, bed/bad, path/pass)의 차이가 약하게 들릴 수 있어요. 헷갈리면 "천천히"로 들어 보시고, 가능하면 원어민 녹음으로 바꿔 주세요.
- iOS에서 **홈 화면 앱으로 녹음이 안 되면** Safari에서 직접 열어 보세요.
- 가상 브라우저(Chromium)로만 테스트했어요. **실제 아이폰·아이패드에서의 소리·녹음은 확인하지 못했어요.** 구글 시트·Apps Script 연결도 가짜 응답으로만 확인했어요.
