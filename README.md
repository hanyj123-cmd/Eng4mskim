# 영어 한 걸음 (어머니용 캐나다 생활 영어 앱)

휴대폰·아이패드에서 열리는 웹앱이에요. 서버 없이 **GitHub Pages**로 올리고, 단어·문장은 **구글 시트**로 늘려 갈 수 있어요.

## 들어 있는 것

- **소리 구분 게임 (스테이지 14개, 414쌍 = 단어 828개)**: 스테이지마다 24~34쌍(단어 48~68개)이에요. 한 판은 그중 6쌍을 무작위로 뽑아 내요.
  f/p, v/b, l/r로 시작해서 y 소리(향수/항수 같은 year/ear), w 소리(과자/가자 같은 wait/eight), i/ee, s/sh, cup/cop, walk/work, called/cold, th/s, th/d, bad/bed, 끝소리(bag/back)까지. 앞 스테이지를 한 판 하면 다음 스테이지가 열려요. 틀려도 감점 없이 마지막에 한 번 더 나와요.
- **실전 영어 (11곳, 124개 표현)**: 되물을 때, 카페·팀홀튼, 마트 계산대, 식당, 병원·약국, 은행, 우체국·택배, 관공서, 이웃·엘리베이터, 길·버스·지하철, 전화. 장소마다 **이런 말이 들려요**(직원이 하는 말 + 대답 예시)와 **이렇게 말해요**(내가 하는 말)로 나뉘어요.
- **실전 듣기 게임**: 직원이 하는 말을 듣고 뜻을 3개 중에 골라요.
- **따라 말하기**: 듣기 → 녹음 → 원래 소리와 이어서 비교 → 스스로 체크. "잘 됐어요" 3번이면 마스터.
- **오늘의 학습 + 출석 도장**: 홈에서 하루 분량이 정해져 있어요 (소리 구분 1판 → 새 표현 → 복습 → 실전 듣기 1판). 전부 끝내면 빨간 도장이 쾅 찍히고(+40점) 출석이 돼요. 도장판에서 달력으로 볼 수 있어요. 하루 분량은 설정에서 가볍게 / 보통 / 알차게(새 표현 2·3·5개, 보통 10~20분)로 바꿔요. 못 한 날이 있어도 벌점 없이 그 다음 날 이어서 해요 (n일차는 날짜가 아니라 해낸 횟수예요).
- **반복 복습(간격 반복)**: 배운 표현은 잘 될수록 1일 → 3일 → 7일 → 14일 → 30일 뒤에 다시 나와요. 안 되면 한 단계 앞으로 돌아가요. 복습할 때가 된 표현은 "오늘의 학습"에 들어가고, 실전 영어 화면에 `복습` 표시가 붙어요. 복습 단계는 하루에 한 번만 바뀌어요.
- **승부욕 장치** (시간제한·가족 경쟁 없음):
  - 연속 정답 **콤보**: 3연속부터 점수 2배, 6연속부터 3배. 최고 콤보 기록이 남아요.
  - **별**: 스테이지·장소마다 정답률 70% 이상 별 2개, 90% 이상 별 3개. 기록을 깨면 "신기록!" 표시.
  - **나 vs 지난주의 나**: 홈 화면에서 이번 주 점수와 지난주 점수를 경주처럼 비교하고, 넘어서면 축하해요.
  - 칭호 10단계(새내기 → 토론토 토박이), 배지 20개(도장·복습 배지 포함), 연속 학습일, 매주 실전 미션 12종.
  - 홈의 **바로 한 판 하기**: 안 해 본 곳이나 별이 적은 곳을 골라 바로 시작해요.
- 글자 크기 3단계, 한글 발음 표기 켜기/끄기

### 이렇게 하세요 (하루 10분)

홈의 **오늘의 학습**에서 위에서부터 차례로 누르기만 하면 돼요. **오늘 학습 시작** 버튼을 누르면 남은 첫 번째 할 일로 바로 가요. 네 가지를 다 하면 도장이 찍혀요.

- 소리 구분 스테이지는 이틀에 하나씩 순서대로 바뀌어요 (1~2일차 f/p, 3~4일차 v/b …).
- 새 표현은 하루 2~5개씩, 장소 순서대로 나와요 (처음엔 되물을 때 표현부터).
- 문장은 "잘 됐어요"를 3번 하면 마스터(⭐⭐⭐)예요. 마스터해도 복습은 계속 나와요.

## 1. GitHub에 올려서 열기

1. github.com 에서 **New repository** → 이름 `english-for-mom` → **Public** → Create.
   (무료 GitHub Pages는 Public 저장소만 돼요. 개인 정보는 들어 있지 않아요.)
2. 이 폴더 안의 파일 **전부**(index.html, app.js, style.css, data.js, config.js, manifest.json, sw.js, icons 폴더 등)를 저장소에 끌어다 놓기: **Add file → Upload files** → **Commit changes**.
3. 저장소 **Settings → Pages → Build and deployment**: Source `Deploy from a branch`, Branch `main` / `/ (root)` → Save.
4. 1~2분 뒤 `https://내아이디.github.io/english-for-mom/` 로 열려요.

## 2. 어머니 아이폰·아이패드에 설치

1. **Safari**로 위 주소를 열어요. (크롬 말고 Safari)
2. 공유 버튼(네모에 화살표) → **홈 화면에 추가**.
3. 처음 녹음할 때 **마이크 허용**을 눌러야 해요.

## 3. 구글 시트로 단어·문장 늘리기 (선택)

1. 새 구글 시트를 만들고 탭 5개를 이름 그대로 만들어요: `groups`, `pairs`, `places`, `phrases`, `missions`
2. 각 탭에서 **파일 → 가져오기 → 업로드**로 `sheet-csv/` 폴더의 같은 이름 CSV를 넣어요 (현재 시트 바꾸기).
3. **공유 → 링크가 있는 모든 사용자 → 뷰어**.
4. 주소 `.../spreadsheets/d/`**`여기가 ID`**`/edit` 의 ID를 `config.js` 의 `SHEET_ID` 에 넣고 GitHub에서 저장.
5. 이제 시트에 줄을 추가하면 앱에 반영돼요. 앱을 **두 번 열어야** 새 내용이 보일 수 있어요. 시트가 안 열리면 내장 데이터로 동작해요.

시트 열 이름은 CSV 첫 줄 그대로 두세요. `pairs`의 `group`은 `groups`의 `id`와 같아야 하고, 그룹 순서가 스테이지 순서예요 (처음 3개는 항상 열려 있어요). `phrases`의 `place`는 `places`의 `id`와 같아야 하고, `who`는 `me`(내가 하는 말) 또는 `them`(들리는 말), `reply`는 들리는 말에 대한 대답 예시예요.

## 4. 진도를 시트에 남기기 (선택)

진도(점수, 연속일)는 기본으로 **그 기기에만** 저장돼요. 시트로도 보고 싶으면 `apps-script/Code.gs` 안의 설명대로 배포하고, 웹 앱 URL을 `config.js` 의 `APPS_SCRIPT_URL` 에 넣으세요. 시트에 `progress` 탭이 자동으로 생겨요. (기록만 남기고, 기기 간 진도 동기화는 아직 없어요.)

## 5. 고칠 때 알아둘 것

- 앱 파일이나 mp3를 고친 뒤에는 `sw.js` 맨 위 `eng-mom-v6` 숫자를 올려요 (v7, v8…). 안 올리면 기기에 예전 버전이 남을 수 있어요.
- 레벨 점수는 `app.js` 위쪽 `LEVELS`, 하루 분량(새 표현·복습 개수)은 `AMOUNTS`, 복습 간격(일)은 `INTERVALS`에서 바꿔요.
- `data.js`는 내장 데이터예요. 시트를 쓰면 시트가 우선이에요.

## 영어 소리에 대해

- 단어와 문장은 **AI 음성(Kokoro, 미국 영어 여성)으로 미리 만든 mp3**예요 (`audio/` 폴더, 보통·천천히 2종류). 원어민 녹음은 아니에요.
- 아이폰·아이패드 기본 음성보다 자연스럽고, 기기나 설정과 상관없이 같은 소리가 나요. 한 번 열어 두면 인터넷이 끊겨도 들려요.
- mp3가 없는 문장(시트에서 새로 추가한 것 등)은 기기 내장 음성으로 대신 읽어요. 이때는 아이폰 옆 **무음 스위치**와 볼륨을 확인해 주세요.
- 원어민 녹음으로 바꾸고 싶으면 같은 이름의 mp3를 `audio/`에 덮어쓰면 돼요. 파일 이름은 영어 문장을 소문자로 하고 글자·숫자가 아닌 부분을 `-`로 바꾼 것이에요 (예: `could-i-get-a-fork-please.mp3`, 천천히 버전은 `...slow.mp3`).
- 새 문장의 mp3를 만드는 스크립트는 `tools/make_audio.py`예요. Kokoro 모델 파일이 필요해서 Claude에게 "새 문장 mp3 만들어 줘"라고 하시면 돼요.

## 알려진 한계 (솔직하게)

- **발음 자동 평가는 아직 없어요.** 지금은 "녹음해서 원어민과 이어 듣기 + 스스로 체크"예요. 자동 평가(Azure 등)는 다음 단계예요.
- AI 음성은 비슷한 소리(예: pine/fine, bed/bad, path/pass)의 차이가 약하게 들릴 수 있어요. 헷갈리면 "천천히"로 들어 보시고, 가능하면 원어민 녹음으로 바꿔 주세요.
- iOS에서 **홈 화면 앱으로 녹음이 안 되면** Safari에서 직접 열어 보세요.
- 가상 브라우저(Chromium)로만 테스트했어요. **실제 아이폰·아이패드에서의 소리·녹음은 확인하지 못했어요.** 구글 시트·Apps Script 연결도 가짜 응답으로만 확인했어요.

## 디자인에 대해

- 컨셉은 **캐나다 도로 표지판 + 유리(글래스)**예요. 뒤에는 호수빛 하늘과 산 능선, 앞에는 반투명 유리 패널이 떠 있어요.
- 표지판은 초록색 안내판(홈·결과 화면), 파란 서비스 표지(메뉴 아이콘), 갈색 관광 표지(이번 주 미션), 노란 진행 막대를 써요.
- 레벨은 캐나다 고속도로 번호판 모양의 방패 아이콘으로 보여요.
- 글꼴 Overpass(고속도로 표지판 글꼴 계열)는 `fonts/`에 들어 있어서 인터넷 없이도 같은 모양으로 나와요 (라이선스: `fonts/OFL-Overpass.txt`). 한글은 기기 기본 글꼴을 써요.
- 이모지 대신 직접 그린 아이콘을 써서 기기마다 모양이 달라지지 않아요.
- 홈 화면 인사말(Good morning / afternoon / evening)은 시간에 따라 바뀌고, 누르면 소리가 나요.
- 색은 `style.css` 맨 위 `:root`에서 바꿀 수 있어요.
